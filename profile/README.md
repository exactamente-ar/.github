# Exactamente

  **Recursos universitarios hechos por estudiantes, para estudiantes.**

  Exactamente es una plataforma abierta donde estudiantes de la Facultad de Ciencias Exactas de la
  UNICEN buscan y comparten parciales, resúmenes y finales de sus materias.

  🌐 **[exactamente.com.ar](https://exactamente.com.ar)**

  ---

  ## 🧩 Proyectos

  | Repo | Qué es | Stack |
  |---|---|---|
  | [`exactamente-frontend`](https://github.com/exactamente-ar/exactamente-frontend) | El sitio público | Astro · React |
  | [`exactamente-backend`](https://github.com/exactamente-ar/exactamente-backend) | La API REST | Bun · Hono · Drizzle · PostgreSQL |
  | [`exactamente-mcp`](https://github.com/exactamente-ar/exactamente-mcp) | Servidor MCP para consultar los datos académicos desde agentes de IA 
  | [`exactamente-workspace`](https://github.com/exactamente-ar/exactamente-workspace) | Metodología, planificación y setup de todo el proyecto |  |

  ---

  ## 🙌 Cómo sumarte

  No hace falta saber mucho para empezar. Hay lugar para código, diseño, contenido e ideas.

  1. **Mirá el [tablero del proyecto](https://github.com/orgs/exactamente-ar/projects/2)**. Todo lo
     que está en **Ready** se puede tomar.
  2. **¿Es tu primera vez?** Buscá los issues con
     [`good first issue`](https://github.com/search?q=org%3Aexactamente-ar+label%3A%22good+first+issue%22+state%3Aopen&type=issues).
  3. **Comentá en el issue** que lo querés tomar y esperá a que te lo asignen.
  4. Leé la **[guía de contribución](https://github.com/exactamente-ar/exactamente-workspace/blob/main/CONTRIBUTING.md)**
     antes de abrir tu primer PR.

  ¿Tenés una idea o encontraste un bug? Abrí un issue en el repo que corresponda: hay templates
  para las dos cosas.

  ---

  ## 💜 Apoyar el proyecto

  Exactamente es gratuito y no tiene publicidad. Si te sirvió, podés ayudar a mantener los
  servidores con un [cafecito](https://cafecito.app/exactamente).
