# Exactamente

**Recursos universitarios hechos por estudiantes, para estudiantes.**

Exactamente es una plataforma abierta para compartir y encontrar material de estudio de la Facultad de Ciencias Exactas de la UNICEN.

Parciales, finales, resúmenes y otros recursos de las materias, reunidos en un solo lugar.

**[exactamente.com.ar](https://exactamente.com.ar)**

## Proyectos

El proyecto está dividido en varios repositorios:

* **[exactamente-frontend](https://github.com/exactamente-ar/exactamente-frontend)** — sitio público de Exactamente. `Astro` · `React`
* **[exactamente-backend](https://github.com/exactamente-ar/exactamente-backend)** — API y acceso a los datos. `Bun` · `Hono` · `Drizzle` · `PostgreSQL`
* **[exactamente-mcp](https://github.com/exactamente-ar/exactamente-mcp)** — servidor MCP para consultar los datos académicos desde agentes de IA.
* **[exactamente-workspace](https://github.com/exactamente-ar/exactamente-workspace)** — documentación, planificación, metodología y configuración del proyecto.

## Contribuir

Exactamente es un proyecto abierto y cualquier estudiante puede aportar.

No hace falta ser desarrollador. Hay cosas para hacer en código, diseño, contenido, documentación y organización.

Si querés sumarte:

1. Revisá el **[tablero del proyecto](https://github.com/orgs/exactamente-ar/projects/2)** y buscá tareas en `Ready`.
2. Si estás empezando, podés buscar **[good first issues](https://github.com/search?q=org%3Aexactamente-ar+label%3A%22good+first+issue%22+state%3Aopen&type=issues)**.
3. Comentá en el issue que querés trabajar en él y esperá a que te lo asignen.
4. Antes de abrir tu primer PR, revisá la **[guía de contribución](https://github.com/exactamente-ar/exactamente-workspace/blob/main/CONTRIBUTING.md)**.

¿Encontraste un error o tenés una idea para mejorar Exactamente? Podés abrir un issue en el repositorio correspondiente.

## Apoyar Exactamente

Exactamente es gratuito y no tiene publicidad.

Si el proyecto te resulta útil y querés ayudar a cubrir los costos de infraestructura, podés hacerlo mediante **[Cafecito](https://cafecito.app/exactamente)**.
